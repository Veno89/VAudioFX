# Validation

`npm run quality:gate` checks sample/dependency source/license/binary integrity, runs Vitest, strict TypeScript plus the Vite build, the Chromium/Firefox development suite, and a separate production offline workflow. Install matching browsers with `npx playwright install chromium firefox` first. On Windows use `.cmd` if PowerShell blocks npm scripts.

Unit coverage: timeline durations/grid/boundary/playhead snapping, trims/moves/split/reverse split, bounded repetitions, track ordering, history, audible track selection, effect/cleanup/loop/export bounds, version 1/2 migration and version 3 portable roundtrips, PCM headers/interleaving, package checksums/path/size rejection, linked stereo gating, quiet-edge padding/silent-region rejection, normalization gain cap, limiter sample counts, detached validated presets, atomic project/preset save recovery, captured-blob persistence, microphone denial/unavailability/interruption/cancellation/repeated take/cleanup.

Browser coverage: import → trim → Creature voice → second layer → preview → save → refresh → WAV; procedural Fireball edits and portable recovery after local sources are isolated; fake microphone repeated takes/pause/persistence/ended tracks; denied microphone and malformed audio/package import; injected storage exhaustion preserving last save; narrow viewport containment; actual Web Audio gain/filter/pan/fade/bypass/reverse/timing/tail/silent-signal/finite-output checks; exact preview-buffer identity and single active playback source; all bundled samples decodable with matching metadata.

Milestone 2 browser checks measure EQ gain, compressor attenuation, individual bypass, audible order changes, gate noise suppression and retained signal, normalization peak, limiter ceiling/count, and unchanged original samples. Native loops wrap on the AudioContext clock, retain the exact buffer, pause within the region, and reject out-of-buffer ranges. Workflows cover custom chain CRUD/reset/reload, cleanup trim/undo, loop preview versus full WAV duration, repetition/undo, arrow nudges, Shift+F10 actions, cross-layer dragging, fit, and portable recovery of cleanup/order/loop settings. Workflow tests reject console errors as well as uncaught exceptions.

Page-lifecycle checks hide and restore an active loop, then hide during a held decode and verify that cancellation prevents native rendering from starting. The restored editor can play again. A unit check holds an old context's close operation while creating a new one and verifies that disposal closes each owned context exactly once.

Milestone 3 checks measure deterministic noise, relative pink/white spectral balance, envelopes/pulsing and finite bounds, native tone harmonics, descending-sweep crossings, and actual sample changes from all four macros. Every template's originals and rendered/decoded WAV are checked, including distinct mix hashes and shared footstep sources. Browser workflows create all seven source types, save/reload them, and recover a portable backup after local originals are removed. Guides exercise a fake-device recorded voice through layering and WAV download, Fireball target identity after renaming, UI repetition undo/redo, creative preset/reset/macro persistence, and narrow layout. Injected storage failure and a deliberately held generation verify recovery and cancellation without unwanted insertion. Prepared-template persistence retains the previous active project.

Microphone automation uses fake devices or mocks, **not real microphone hardware**. Audio tests inspect rendered samples rather than claiming a human listening review. Actual Edge, real device disconnection, feedback/monitoring latency, assistive technologies, real storage eviction and lower-memory devices require manual qualification. Chromium tests cover the underlying engine used by Chrome/Edge, but do not certify those installed browsers.

The E2E runner uses dedicated QA port 5183 (override with `VAFX_QA_PORT`), separately from the dev server on 5173. It refuses an occupied QA port, logs owned PIDs, bounds startup and suite time, and stops exact owned process trees in `finally`. It never stops unrelated browser or Node processes. Screenshots and traces go into ignored `.qa/` and `test-results/` directories.

Milestone 4 measures independent pitch frequency/duration/stereo balance, DC/hum suppression, gain/pan/filter automation, split interpolation and full-lane limits, version 2 migration, and original preservation. A compressed-source regression checks declared versus decoded durations through normal/reversed/pitched rendering and rejects unavailable trims. Worker codec checks cover all three formats at both sample rates/channel counts, native decoding, headers, exact WAV byte equivalence, Vorbis granule counts and lossy padding. Cancellation terminates worker encoding and permits retry. Advanced edits survive undo/reload/portable recovery; waveform keyboard seeking and narrow controls are exercised. A 60-second stereo composition reports exact allocation counts and measures event-loop gaps. Production tests install the shell, disconnect the browser, reload, generate/pitch and export MP3 with no errors.

Console errors forwarded through Vite also fail the runner, even if page-level event capture misses them. Editor checks capture browser-side error stacks through an exposed binding and flush callbacks before their final assertion. Suites have a ten-minute deadline and clean up tracked processes. Focused production checks can be run with `node scripts/run-e2e.mjs --production tests/e2e/offline.spec.ts` after a build.

Milestone 5 adds malformed ZIP local/central/end-directory, flags, CRC/SHA, manifest/UTF-8 and provenance checks; empty-original rejection; forced IndexedDB close/reopen and canceled partial-write rollback; and oversized/malformed WAV/Vorbis declaration checks before native decoder construction. Portable recovery after disposable IndexedDB deletion preserves original bytes, provenance and advanced edits without external requests. A synthetic maximum-size renderer/package workload checks exact buffer counts, hash preservation, abort and UI timer responsiveness; optional Windows profiling records owned browser-process memory and empty-editor baselines. See [release qualification](release.md) for the measured scenario and limits.

Automated axe scans cover the empty editor, generator, selected/expanded inspector, export/project/idle-recording/help/license dialogs and template library, with zero permitted violations for the configured WCAG A/AA and best-practice rules. Forward/backward Tab stays within the modal, Escape restores trigger focus, and clip Space activation retains native button semantics. These checks do not replace screen-reader or human accessibility review. Production checks compare actual security headers and generate/pitch/export MP3 and OGG plus a portable backup after offline reload. `check:release` verifies the built distribution and Netlify header agreement. `package:preview` verifies the ZIP bytes and records exact uncommitted-source provenance.
